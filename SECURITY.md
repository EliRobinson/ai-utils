# Security

Please report a security problem privately, not in a public issue.

Use GitHub's private vulnerability reporting for this repo: open the
**Security** tab of [EliRobinson/ai-utils](https://github.com/EliRobinson/ai-utils)
and choose **Report a vulnerability**
(<https://github.com/EliRobinson/ai-utils/security/advisories/new>).

Say what you found, where, and how to reproduce it. You will get a reply on the
advisory.
